gemma-architect (Gemma-CAD)

April-May 2026 (first commit 2026-04-30). Live: wordingone.github.io/gemma-architect. Code: github.com/wordingone/gemma-architect (links pinned to commit 3f43ee6). No feature work since 2026-05-25.

Role: I designed and directed it; most of the code was written by AI coding agents under my review (1,009 of the 1,348 commits carry an AI (Claude) co-author trailer; this is a lower bound, because agent commits without a trailer are not counted).

What it is

Built for the Gemma 4 Good Hackathon (Kaggle + Google DeepMind), deadline 2026-05-18. "Gemma 4 E4B-it (stock, no fine-tune) + replicad geometry kernel + web-ifc all run inside a single tab." The model writes a short geometry program; the browser meshes it with OpenCASCADE and can export IFC4. WEB-CAD continued from this code.

What was measured

  • Measured 9/9 bundled demos pass in a self-test without a browser, and 19/19 rows of a small design-language corpus compile. These are the project's own tests.
  • Measured In-browser decode speed of about 2 tokens/s on this deployment (see WEB-CAD).

Limits

The canned demos are answered from a 60-row prompt cache, not generated live by the model; only prompts that miss the cache go to the model; some cache rows come from an earlier fine-tuned Gemma 3 model's outputs (README). The hackathon write-up in submission/ is marked a historical draft whose claims were not independently verified; for example, IFC import was checked only by re-parsing, not in Revit or ArchiCAD.
