Ember

June-October 2026; no commits since 2026-10-10 (paused). github.com/wordingone/ember (links pinned to commit df2a2d6, 2,449 commits on master). Research log: wordingone.github.io/ember.

Role: I designed and directed Ember and reviewed the work; AI coding agents wrote most of the code and ran most of the experiments. 457 of the 2,449 commits on master carry an AI (Claude) co-author trailer; the repository has no single authorship statement.

What it is

"A project to build an AI model from scratch on one home computer with one consumer graphics card, and to run it locally. No borrowed model weights, teacher models or judge models are used." The card is one RTX 4090-class 24 GB GPU. The target is a sparse decoder for text, images and audio; its minimum size of 3,000,000,000 parameters is a goal threshold, not a current measurement. Only text (and some image-text) training has run.

What was built

  • Implemented A governed training loop: each hour of training produces a child checkpoint that is kept only if a recorded ruling accepts it. A refused child is not retained and credits zero positions to the lineage. The rule is in code.
  • Implemented A research log in which every hypothesis carries a refutation criterion frozen before the run (see How I work), and a receipts index of 1,022 rows.
  • Implemented ember-cli, the command-line agent tool used to run and watch training.

What was measured

  • Measured Retained training across the kept lineage: 6,064,082,944 token positions over 1,480,489 steps, 33 checkpoints deep, with a duplicate-credit check confirming each hour is counted once.
  • Measured Benchmarks are at chance: ARC-Challenge accuracy 0.2295 over 1,172 questions (chance 0.25); HellaSwag 0.2588 over 10,042 (chance 0.25). A public receipt for an older step-50 checkpoint shows ARC accuracy 0.2227.
  • Found A profiling probe had measured the wrong execution path: it never called CUDA graph capture, so 76 of 142 registry rows described an uncaptured step while training ran a captured one (an uncaptured trace near 1.762 s per step against about 0.187 s captured). The replacement probe refuses to report if capture did not occur. (The source file is 6.6 MB; search it for "76 of 142".)
  • Found Data lineage: an audit found that the largest prose source, FineWeb-Edu (~29% of corpus bytes), was selected by a classifier trained on Llama-3-70B-Instruct annotations, an outside model's influence on the training data. It was later dropped, but whether the current run's corpus is clean is "not established". So the lineage is not certified clean.

What is open

The main goal was not reached. "No current checkpoint is an Ember model"; the latest candidate is "not admitted", with no capability credit and sufficient pretraining not proven. No benchmark result is above chance.
