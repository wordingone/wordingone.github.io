The Search

March-June 2026. Concluded. github.com/wordingone/the-search (all links below pinned to commit 0c1a964).

What it is

A long experimental record on one question: "Can a system improve itself by criteria it generates?" The first era used ARC-AGI-3 game environments and MBPP; the second era used ARC-AGI-1 program synthesis. Candidate learners were judged against a written set of constraints (R1-R6 in the paper; R0 was added and R1 rescoped by an amendment in May 2026).

What was built

Experiment scripts and logs for more than 1,000 experiments: the paper says "1000+ experiments across 14 architecture families", and experiment step numbers in experiments/ run up to 1399. (A summary file counts 792 experiments for the first era alone.) Plus a manuscript, docs/paper.pdf (unpublished, not peer reviewed).

What was measured

  • Measured Best score from the README's "R2-compliant" learners, which did not satisfy the full constraint set (R4 is marked "Not satisfied"): "~1e-5 to 1e-4 depending on game draw (Steps 1349-1366)"; game-draw variance dominated the differences between architectures.
  • Measured No learned action selection beat random actions in the first era.
  • Measured Transfer: "Zero genuine transfer across all substrates tested"; a 100-draw paired test with fixed random seeds gave 0-0-100 ties, p=1.0 (Step 1377).
  • Measured Second era: the reach ladder closed at D=10/200 held-out ARC-AGI-1 tasks, with 185 of 200 runs ending because the search budget ran out.

What is open

The paper's own conclusion: "Whether a substrate exists inside all six walls remains open." An earlier claim in the repo that one constraint (R3) was "solved by composition" has been marked superseded: the test measured a representation change against a provisional threshold, not a gain in task performance (note in docs/PAPER.md). Two planned stages were never run (STAGE_MAP).

Note: the repository README still describes the first era as active work; the summary file STAGE_MAP.md records the second era as concluded in June 2026, while its four-faces milestone is still listed as open.
