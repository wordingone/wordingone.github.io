Projects

Each page separates what was Implemented from what was Measured, and says what is still open. Most numbers link to the public file and line they come from, pinned to a commit.

  • Ember (June-October 2026, paused) An attempt to train a foundation model from scratch on one RTX 4090, with no borrowed weights. No checkpoint admitted; early-checkpoint benchmark scores at chance.
  • ember-cli (2026) Ember's command-line agent tool. An unreleased branch runs third-party open-weights models on one GPU; three issues from agent blind tests are open.
  • The Search (March-June 2026, concluded) More than 1,000 agent-run experiments on whether a learning system can improve itself by criteria it generates. Results mostly negative; measured transfer was zero.
  • WEB-CAD (April-June 2026) An experimental CAD workbench in the browser, with an in-browser Gemma 4 model (about 2 tokens/s) that turns prompts into editable geometry.
  • gemma-architect (April-May 2026) The original hackathon project WEB-CAD grew from. Its bundled demos are answered from a prompt cache.
  • Genesis Forge (2026) An offline Windows desktop app around Microsoft's TRELLIS 3D model. Most of the model code is Microsoft's.
  • Weight-space read experiment (November 2026, in progress) Predicting what attention heads do from weights alone. No public record yet; no result claimed.
