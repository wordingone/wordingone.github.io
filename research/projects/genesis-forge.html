Genesis Forge

2026. github.com/wordingone/genesis-forge (links pinned to commit e8dd34c).

Role: I directed the packaging work, written by AI coding agents under my review. Most of the model code is Microsoft's: the vendored TRELLIS, TRELLIS.2 and CUDA-extension folders hold far more code than the app's own gui/ and tests/ folders, and the root licence is Microsoft's MIT licence.

What it is

A desktop application for 3D asset generation from text and images, built on Microsoft's TRELLIS. The contribution is making it run offline on Windows: an Electron + FastAPI app with pre-compiled CUDA extensions.

What was measured

  • Self-logged One image-to-3D run: 239.2 s total, 23,716 MB peak GPU memory. These figures come from the project's own progress log, not an independent benchmark, and the hardware is not stated beside them.

What is open

The progress log is not consistent with itself: its header calls the pipeline "production-ready" and "frozen/stable" (2026-02-01), while an earlier active issue records a failed TRELLIS.2 generation (shape scored 0.5/10) with a root cause identified. The licence for the app's own code is not yet decided.
