Weight-space read experiment

November 2026. In progress. No public code or results yet.

Role: I directed it; AI coding agents wrote and ran the code.

What it asks

Can you tell what an attention head does from its weights alone, without running the model on any input? The test case is the induction head: a head that finds an earlier copy of the current token and copies what came next. Interpretability work usually finds these heads by running the model; this experiment tries to predict them from the weights first and then check.

Method (as planned)

  • Planned Score every head from its weights: how strongly it composes with an earlier head that attends to the previous token, measured in the residual-stream basis, taking the model's position encoding into account.
  • Planned Rank all heads by that score and write down the top five before looking at any published list or running any forward test, with the pass/fail rule fixed in the same commit.
  • Planned Repeat on a small public model whose induction heads are already published, so anyone can check the prediction.
